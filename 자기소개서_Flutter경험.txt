[코아아이티 지원 동기 및 포부]

[Java Spring 기반 웹개발 역량]

복지24 프로젝트에서 Spring MVC와 MyBatis를 활용해 복지 서비스 통합 플랫폼을 개발했습니다.
Controller-Service-Mapper 계층 구조를 직접 설계했으며, REST API 엔드포인트를 구현하여 JSON 형식의 요청과 응답을 처리했습니다.
또한 인터셉터를 활용한 세션 검증과 권한 체크 로직을 구현하며 Spring의 요청 흐름을 깊이 이해할 수 있었습니다.

WITHUS 프로젝트에서는 프레임워크 없이 순수 Java Servlet으로 MVC 패턴을 직접 구현했습니다.
40개 이상의 Servlet 컨트롤러와 DTO 클래스를 설계하고 DAO-Service-Controller 계층을 수동으로 구성하면서,
Spring Framework가 내부적으로 어떻게 동작하는지 원리부터 체득할 수 있었습니다.

[RDBMS 및 공공 SI 프로젝트 경험]

두 프로젝트 모두 MySQL을 기반으로 데이터베이스를 설계하고 운영했습니다.
복지24에서는 회원, 기부, 봉사 등 20개 이상의 테이블을 설계하며 외래키 관계와 인덱싱 전략을 적용했고,
MyBatis를 활용해 동적 쿼리를 작성했습니다.
조회 성능 개선이 필요한 구간에는 Redis 캐싱을 도입하여 응답 시간을 3초에서 1ms로 단축하는 성과를 얻었습니다.
WITHUS에서는 JDBC를 직접 다루며 PreparedStatement를 활용한 SQL 인젝션 방지와 트랜잭션 처리를 경험했습니다.

특히 복지24에서 정부 공공데이터포털 API를 연동하여 수백 건의 복지 서비스 정보를 실시간으로 조회하고 가공하는 기능을 구현했습니다.
이 과정에서 정부 API 규격에 맞춘 데이터 파싱과 에러 핸들링을 경험했으며, 이는 공공 SI 프로젝트에 바로 활용될 수 있다고 생각합니다.

[팀 협업 및 기여 포부]

WITHUS 프로젝트에서 4인 팀의 기획과 커뮤니케이션을 주도했습니다.
주 2회 코드 리뷰를 진행하고 네이밍 규칙과 코딩 컨벤션을 함께 정립하여 코드의 일관성을 높였습니다.
개발 중 팀원 간 데이터 형식 충돌 문제가 발생했을 때, 제네릭 기반의 공통 응답 클래스를 설계하여 문제를 해결한 경험도 있습니다.

이러한 Java Spring 웹개발 역량과 RDBMS 설계 경험, 그리고 공공 데이터 연동 경험을 바탕으로
코아아이티의 공공 SI 프로젝트에 즉시 기여할 수 있는 개발자가 되겠습니다.
